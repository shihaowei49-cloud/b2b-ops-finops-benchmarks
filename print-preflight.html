KDP paperback spine widths

Use the processed print page count. KDP rounds an odd manuscript count up to the next even number.

  • Black ink on white paper: spine = print pages × 0.002252 in.
  • Black ink on cream paper: spine = print pages × 0.0025 in.
  • Outer bleed is 0.125 in per edge. Full-wrap width is 2 × trim width + spine + 0.25 in. Full-wrap height is trim height + 0.25 in.
  • Place spine text at least 0.0625 in from each fold. The available text width is max(0, spine − 0.125 in). KDP prints spine text on books above 79 print pages.

11 × 17 Tabloid duplex fold calibration

Print two imposed PDF spreads on one landscape Tabloid sheet. Choose 100% Actual Size, one PDF page per side, and short-edge duplex.

Panel order with each spread viewed upright
PDF page / sheet sideLeft panelRight panelFold check
1 / Outside4 · Back cover1 · Front coverPage 1 faces out.
2 / Inside2 · Inside left3 · Inside rightBoth pages are upright.

Measure 8.5 in from either side across the 17 in edge to the center ticks. Fold to 8.5 × 11 in and read 1 → 2 → 3 → 4. Check that the two faces line up and that type and other critical artwork stay within the specimen’s 0.375 in safe margins.

If the inside spread is upside down, check the duplex edge setting and run a second proof. If both sides are upright but the panels are out of order, turn off booklet imposition and restore the PDF page order in the print driver.
